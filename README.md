# 🍅 多主题任务番茄钟 (Pomodoro Timer)

一个简单、美观且功能实用的单网页番茄钟工具。支持绑定本次计时任务，并提供多种视觉主题自由切换。

## ✨ 核心功能
- **番茄钟计时**：带开始/暂停/重置功能，专注时长可在 15 / 25 / 45 分钟间一键切换，自动记忆上次选择。
- **专注/休息循环**：专注结束后自动进入 5 分钟休息倒计时，可随时跳过；休息结束回到专注待命，任务内容保留，方便连续作战。
- **番茄养成花园**：每完成一个专注番茄，左侧的番茄树就会长大一点（种子→幼苗→小树→开花→结果→成熟）；连续完成 5 个后即可收获，收获时下起番茄雨庆祝；中途放弃会让树枯萎一点。成长阶段轨道实时显示当前种到了哪一步。
- **番茄小精灵**：计时环上的番茄有表情变化——专注时皱眉、休息时放松、完成时开心；连点它 10 次会触发隐藏的"番茄雨"彩蛋。
- **随机语录**：每次开始专注，状态栏会随机出现一句励志语录。
- **任务绑定与记录**：计时开始前需填写当前任务，并自动保存在下方历史列表中，支持单条删除与二次确认清空。
- **今日统计**：实时显示今天完成的番茄数与累计专注分钟数。
- **键盘快捷键**：空格键即可开始/暂停计时。
- **标签页提醒**：休息结束时标签页标题闪烁提醒，切回页面自动停止。
- **一键切换主题**：内置 3 种不同风格的设计方案，满足不同学习与工作场景。
- **本地记忆 (localStorage)**：自动保存你选择的主题、专注时长、花园成长和历史任务记录，刷新网页不丢失。
- **移动端适配**：小屏幕下自动堆叠成单列，手机也能舒适使用。

## 🛠️ 技术栈
- HTML5
- CSS3 (CSS Variables)
- JavaScript (Vanilla JS)
